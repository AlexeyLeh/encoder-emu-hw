# Иммитатор энкодера

## Описание

Устройство для выдачи последовательности прямоугольных импульсов.  

Направление определяется порядком появления сигналов на двух выходах.

Основные параметры работы:

* Скорость выдачи испульсов (задается частотой)
* Количество импульсов

Реализовано на Ардуино UNO, чип AtMega328P

## Управление

Управление через COM-порт (COM 9600) подачей управляющих команд.

### Установка параметров

Количество шагов (импульзов):

* c100\\n - вперёд 100 шагов
* c-200\\n - назад 200 шагов

Частота испульсов (задается в Hz):

* f1000\\n" - 1000Hz

Получить текущие параметры:

* i
```
FREQ:7250
CLICKS:100000000
WAY:>
TIMER:ON:F7250:HW29000:L0:T64985:98178369
```
 
### 

### Запуск

* r\\n - запустить
* e\\n - остановить
